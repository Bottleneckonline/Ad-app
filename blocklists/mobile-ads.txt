# AdFree mobile ad networks list, maintained by hand in this repo.
#
# The general list (blocklist.txt) names individual hostnames. Ad SDKs keep adding new
# ones (new regions, new CDNs, new "gateway" hosts), so a list of hosts lags behind.
# This list blocks the whole domain of each company whose domain only serves ads,
# which also covers future subdomains. A parent entry blocks every subdomain.
#
# Hosts marked [sdk] were found inside the real SDK files by scripts/sdk-audit/audit.py
# and were not blocked by blocklist.txt before this list. Do not add domains that also
# serve normal app content (facebook.com, google.com, unity3d.com, apple.com, ...).
